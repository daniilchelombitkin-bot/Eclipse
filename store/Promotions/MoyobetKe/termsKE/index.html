1 Participants

  • Participation is open only to individuals aged 18 years and above.
  • MoyobetKE does not verify the age of participants at the time they complete the giveaway conditions; however, prizes can only be awarded to individuals of legal age.
  • If a participant is found to be under 18, their right to receive a prize will be annulled.

2 Participation Rules

  • An entry is considered valid only if all conditions stated in the campaign post are fulfilled (follow, like, comment/message, complete the challenge).
  • Only the last 100 valid entries per challenge are counted.
  • Participation is free and voluntary.

3 Comment Processing & Table Management

  • Each participant is recorded in the campaign tracking table throughout the giveaway period.
  • Comment submissions close every Friday after 17:00 (EAT).
  • Comments posted later than 16:59:59 are not counted and are not added to the table.
After the comment submission period ends:
  • Duplicate comments are removed. Only the latest comment from each participant remains (e.g., if someone commented on Monday, Wednesday, and Friday — only Friday's comment is valid).
  • Once duplicates are removed, the table is renumbered in reverse order, starting from the last valid comment (up to a maximum of 100).
  • Winners are determined according to the pre-published formula (positions 1, 21, 41, 61, 81).
Winner Selection Based on Participant Count
< 100
If the number of participants is less than 100, we select according to the following principle: 1st, 21st, 41st, 61st, and the last participant.
< 60
If the number of participants is less than 60, we select according to the following principle: 1st, 21st, 41st, the second-to-last, and the last participant.
< 40
If the number of participants is less than 40, we select according to the following principle: 1st, 21st, and the last three participants.
< 20
If the number of participants is less than 20, we select according to the following principle: 1st, and the last four participants.

4 Winner Selection
